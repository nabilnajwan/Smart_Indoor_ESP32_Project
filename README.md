# Smart Indoor Environment Monitoring and Alert System

This project is an ESP32-based indoor monitoring system developed for the Sensor Based System final project.

## Features

- Real-time temperature and humidity monitoring using DHT11
- Gas or smoke detection using MQ-2 sensor
- Light level monitoring using LDR sensor
- OLED display for local readings
- Buzzer alert for warning and critical conditions
- Web dashboard with live data, history, charts, and settings
- Login and sign-up system for user-specific device data
- PHP and MySQL backend
- Real-time insight and action recommendations

## Hardware Components

- ESP32
- DHT11 sensor
- MQ-2 gas sensor
- LDR sensor
- OLED SSD1306 display
- Buzzer
- Push button
- Sound sensor
